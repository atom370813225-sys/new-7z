# 解压位置与任务中心设置

日期：2026-11-25。涉及三处：设置 → 常规 → 解压位置、任务中心的已完成卡片、任务中心的「解压完成后自动关闭窗口」。

## 功能

**解压位置（设置 → 常规）**

- 「解压到固定目录」开关：开启后使用下方目录作为解压目标，关闭时沿用压缩包所在的文件夹。
- 「默认解压目录」文本框 + 「选择文件夹」：只接受完整路径（如 `D:\解压`）。路径无效时提示并恢复上一个有效值，输入框失焦或按回车即保存。
- 「在该目录下新建与压缩包同名的子文件夹」：勾选时目标为 `目录\压缩包名`，不勾选直接解压到该目录。
- 生效位置：主窗口「全部解压 / 解压选中」对话框、主页「批量解压」的目标目录、右键「解压到…」（单个归档的目标目录、多个归档的根目录）、右键「智能解压」的根目录。每次解压前仍可修改目标。右键「解压到当前文件夹」语义明确，不受此设置影响；拖拽解压仍走临时目录。

**任务中心：已完成卡片与「打开解压目录」**

- 成功完成的解压任务不再立即消失，而是保留为「已完成」卡片，状态显示「已完成」、进度 100%，并隐藏取消与重试。
- 解压任务的卡片显示「打开解压目录」，点击用资源管理器打开 `Destination`；目录尚不存在时退回上一级并给出提示。压缩、测试等任务仍显示「打开所在文件夹」。
- 最多保留最近 12 个已完成解压任务，超出时移除最旧的卡片；顶部「清除已完成」可一次性清空。任务完成时就地更新卡片，不重建页面。
- 右键任务窗口（`ShellTaskWindow`）在解压类任务完成后，底部按钮文字同样改为「打开解压目录」。

**解压完成后自动关闭窗口（任务中心）**

- 复选框「自动关闭 New7z 窗口」：勾选后，解压任务成功完成即关闭主窗口。
- 关闭前排空队列：还有任务在排队或运行（`jobs.Any(j => j.CanCancel)`）时不关闭，等最后一个任务结束后再关闭，避免批量解压被中断。
- 只对解压任务生效，压缩、测试、失败或取消都不触发。
- 设置保存在 `settings.json`，下次启动仍生效。右键任务窗口除原有「任务成功后 → 自动关闭」外，也把该设置用于解压类任务。

## 实现

设置字段（`src/New7z.App/UserSettings.cs`，写入 `%LOCALAPPDATA%\New7z\settings.json`）：

- `UseDefaultExtractFolder`（bool，默认 false）
- `DefaultExtractFolder`（string，默认空）：加载时经 `NormalizeExtractFolder` 规整，非完整路径或非法路径一律退为空串，空串时强制关闭开关。
- `ExtractIntoSubfolder`（bool，默认 true）
- `CloseAfterExtraction`（bool，默认 false）

路径计算集中在 `ShellPaths`（`ShellRequest.cs`）：`PreferredExtractFolder` 返回已配置目录或 null，`PreferredExtractTarget` 按子文件夹选项返回 `目录\压缩包名`。调用点：`MainWindow.ExtractDialogAsync`、`MainWindow.BatchExtraction`、`ShellTaskWindow.Configure` / `PrepareTargets` / `ProcessArchiveAsync`。

任务中心（`MainWindow.xaml.cs`）：`ArchiveJob` 新增 `Extract`、`KeepCompleted`；`QueueJob` 增加 `extract` 参数（解压任务传 true）。`CompleteJob` 把成功的解压任务移出 `jobs`、插入 `completedJobs`（上限 `MaxCompletedJobs = 12`），旧卡片经 `RemoveTaskCard` 同步移除。卡片统一由 `BuildTaskCard` 生成并返回 `Refresh`，`taskCards` 记录任务到卡片的映射。自动关闭放在 `QueueJob` 的 `Run` 尾部，在队列回调与状态栏更新之后执行。

右键任务窗口（`ShellTaskWindow.xaml.cs`）：构造时读取一次设置；完成后的自动关闭条件为「成功 且（右键窗口自身的自动关闭 或 解压类任务且 `CloseAfterExtraction`）」。
